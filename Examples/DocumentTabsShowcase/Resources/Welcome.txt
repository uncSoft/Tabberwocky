# Welcome   #getting-started

This is a real SwiftUI DocumentGroup app.

Each tab above is a separate document window that macOS has merged into a
native tabbed window — the same tabs you get for free from DocumentGroup.

What's different here: the tab bar is restyled to match the app's theme.
Try the Dark / Light / Midnight switch in the header and watch the tabs
re-theme live.

Things to try:
  • Click between tabs — the accent outline + label follow the active one.
  • ⌘N or the + button — open another tab; it gets styled automatically.
  • Switch the theme — bar, fill, outline, and labels all update.
  • RIGHT-CLICK a tab — two submenus: "Tab Color" (the fill) and "Label Color"
    (the text), each with presets, a custom color, "From #tag", or Clear. They're
    independent, so you can do a teal tab with a yellow label. Try "From #tag" on
    this file (it has #getting-started), then edit the tag and watch it live.
  • Pick a color, then quit and relaunch — it comes back. Fixed colors persist
    via Tabberwocky's TabberwockyColorStore (UserDefaults, keyed by file URL).
    ("From #tag" is a live mode, so it stays for the session.)

Tab groups (PoC):
  • The sidebar lists color-coded GROUPS. All tabs live in ONE native tab group;
    a "group" is just a color + collapse state over a subset of them.
  • Click a group header to COLLAPSE/EXPAND it — collapsed groups drop out of the
    tab bar, so you can focus or cycle. (The last open group won't collapse.)
  • "＋" in the sidebar makes a new group; RIGHT-CLICK a tab → "Move to Group" to
    assign it. The tab recolors to its group and keeps focus.
  • Why one window: a native tab group IS one window, so multiple real groups
    would be multiple windows. Keeping everything in one group + collapse/color is
    how it stays self-contained.
